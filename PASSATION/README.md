L’inventaire des fichiers et leur provenance sont dans [INVENTAIRE_SOURCES.md](INVENTAIRE_SOURCES.md). Le compte rendu détaillé se trouve dans [DOSSIER_PASSATION_2026-09-25.md](DOSSIER_PASSATION_2026-09-25.md).
